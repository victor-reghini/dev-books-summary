# dev-books-summary
summary of development related books


The idea is to summarise books written for developers, creating examples and saving time on the learning curve.
Every book must have its own folder with exercises, explanations and examples of use cases.

Some references are:
https://www.w3schools.com/ (how it has different courses with topics, subtopics, examples and exercises)
https://learning-design-patterns.netlify.app/#/ (style, color coding, visual reference)
https://protocol-explorer-alpha.vercel.app/ (example of depth of the content and creativity, visual flowcharts/animations)

The app should not be a book written online, but a summary, where the user can go to learn the concepts more visually and review the information when needed. The book pages/courses should explain almost every chapter like a review of the book, like the app is a teacher and the website is its classroom.
